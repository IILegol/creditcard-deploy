План A/B-тестирования модели дефолта

Концепция

- Контрольная группа (A): текущая модель v1
- Тестовая группа (B): новая модель v2
- Сплитование: случайное 50/50 по хешу 'client_id' (например, 'hash(client_id) % 2').
- Продолжительность: 2 недели или до накопления 10 000 предсказаний в каждой группе (для статистической значимости).

Метрики

Основная метрика
- F1-score для класса дефолта (class 1). Позволяет балансировать Precision и Recall.

Дополнительная метрика
- Precision - доля истинных дефолтов среди всех предсказанных дефолтов. Выбрана потому, что в банке критично минимизировать ложные срабатывания (не отказывать платёжеспособным клиентам).

Бизнес-метрики

1. Expected Financial Loss:
    'E[Loss] = FP * Cost_FP + FN * Cost_FN', где:
    - 'Cost_FP' — упущенная прибыль от отказа хорошему клиенту.
    - 'Cost_FN' — реальные потери от выдачи кредита дефолтеру.
   
2. Approval Rate при фиксированном уровне риска:
    Доля одобренных заявок при пороге вероятности, 
    при котором доля дефолтов в портфеле не превышает допустимую.

Статистический анализ

- Тест: двухвыборочный z-test для разности пропорций (или t-test для непрерывных метрик вроде F1).
- Доверительные интервалы: 95% CI для разности метрик между группами.
- Критерий успеха: 
    - Нижняя граница 95% CI для разницы F1 (v2 - v1) > 0.
    - p-value < 0.05.
    - Прирост Precision не приводит к критическому снижению Approval Rate.
